### 移除“待处理”页后的对象入口

| 既有对象 | 新入口 | 空/失败状态 |
|---|---|---|
| 草稿内容 | 所属表显示“草稿”；表列表有待整理筛选 | 模型不可用时保留原始草稿和手工编辑入口 |
| 有歧义的 AI 输出 | 原对话中的分类调整卡，跳转内容编辑 | 跨会话无来源捕获落入收件箱，保留原文、人工归表 |
| 全局知识候选 | 原对话确认卡与全局知识管理页 | 两处引用同一候选 ID/状态，重复点击只提交一次 |
| OneDrive 同步冲突 | 同步页的冲突分组 | 逐条保留本地/远端副本；无静默覆盖 |
| 回收站中的整表 | 回收站入口 | 超期显示已清理，不伪造恢复按钮 |

迁移交付前，要用旧版本 fixture 中每类待处理对象逐项验证入口可达；数据不足或无来源时显示明确空态，不自动丢弃、不自动审批。

## 2. AI 工具契约

所有工具由会话读取/新增/修改与删除权限约束。结构提案工具不执行结构变化；UI 点击产生一份绑定内容摘要和目标版本的确认。确认/拒绝按钮不是模型可调用工具。

### 查询

```json
table_search({"query":"期中考试","limit":5})
table_list({"role":"custom","limit":20,"cursor":null})
content_search({"table_ids":["tb_exam"],"types":["todo","schedule"],
  "time_from":"2026-10-29T00:00:00+08:00","time_to":"2026-11-05T00:00:00+08:00",
  "field_filters":[],"query":"准考证","limit":5,"cursor":null})
content_read({"id":"sc_exam","if_revision":4,"max_chars":1200})
```

OpenAI 兼容接口中的函数名只能使用字母、数字、下划线和短横线；表工具以 `table_search`、`content_read` 等下划线名称发送。客户端只在本地调度时映射回 `table.search`、`content.read` 等内部操作名，已持久化的操作卡继续使用点号操作名。

搜索结果返回稳定 ID、表 ID/名称、类型、revision、摘要和是否截断。读取指定 ID 时还需检查 revision；关闭读取权限时连同索引摘要、结果缓存一并不可读。沿用现有每轮搜索数、返回数、正文量及详情读取预算，不因按表检索重置预算。

### 表内内容动作

```json
content_create({"table_id":"tb_exam","type":"todo","title":"确认准考证",
  "body":"","due":"2026-10-30T20:00:00+08:00",
  "custom_values":{"fld_term":"fall_2026"},"idempotency_key":"..."})
content_update({"id":"sc_exam","if_revision":4,
  "changes":{"start":"2026-11-02T14:00:00+08:00"},"idempotency_key":"..."})
content_move({"id":"td_homework","if_revision":2,"to_table_id":"tb_exam",
  "field_mapping":{},"idempotency_key":"..."})
content_delete({"id":"nt_exam_notes","if_revision":1,"idempotency_key":"..."})
schedule_change({"event_title":"老师调整考试时间","event_body":"由周五改到周一",
  "event_occurred_at":"2026-10-29T09:30:00+08:00",
  "schedule_id":"sc_exam","if_revision":4,
  "new_start":"2026-11-02T14:00:00+08:00","new_end":"2026-11-02T16:00:00+08:00",
  "idempotency_key":"..."})
```

内容工具检查当前会话权限、显式目标、字段类型、版本、幂等键和全局知识范围，不逐次询问内容操作。删除单条仍沿用既有 10 分钟撤销账本；整表恢复的 30 天期限不自动扩展到单条删除。

`schedule.change` 是一个可恢复操作：先通过本地日程标题/时间/关联查出唯一目标；若零项或多项匹配则返回 `needs_clarification`，不写任何内容。准备好事件、日程两个前像及幂等记录后提交两项变更，成功回执分别带事件 ID/版本和日程 ID/新版本。异常时按 compare-and-set 撤销已完成部分并回报各对象实际状态；再次使用同一幂等键返回原回执。

### 需用户点击确认的表结构

```json
table_propose({"operation":"create|rename|delete|upsert_field|delete_field",
  "table_id":"tb_exam","expected_revision":4,
  "payload":{"name":"课程","type":"single_select","options":[...]},
  "idempotency_key":"..."})
```

此工具只保存候选并返回 `pending_confirmation`，不改表、不先创建内容；消息卡显示完整目标、字段影响或删表的内容数量/30 天恢复期限。确认执行时重读会话权限、候选会话归属、表 revision、默认表角色和受影响内容数量；任何变化使候选 `stale`，必须在原对话展示新的变化再确认。拒绝和超时不产生副作用。全局知识仍调用原审批路径，不接受表结构确认卡替代。

所有写工具返回 `applied | rejected | needs_clarification | stale | conflict | failed` 之一及操作 ID、目标 ID、旧/新 revision、是否可撤销、实际部分结果。AI 必须依据回执回答，模型原文不能冒充执行结果。

## 3. 集中实施建议与 P0 验收数据

- 待办截止值只影响日历投影，不改变 `todo` 类型；只有明确执行/参加安排的内容创建为日程。自然语言日期不清时要求澄清。
- 字段日期只表示附加信息，不成为日历业务时间。日期或时区缺失的时间条件不通过隐式猜测补齐。
- 笔记和条目文件使用稳定 ID。无归属普通知识→普通笔记默认事件表；已确认全局知识保留现行知识仓及审批，不迁入任何表。
- 恢复冲突时逐对象返回冲突；整表其它无冲突项目恢复后，回收站剩余前像维持可恢复态到期。到期以删除时记录的设备 UTC 时刻判定；设备时钟异常只延后清理，不提前清除。

P0 手工走查至少包含：

1. 新建空表，仅编辑正文；加入待办/日程/事件/笔记和六种字段，重开仍一致。
2. 同一周五日期的待办显示在待办列表/日历；只写“周五”时间文字的普通笔记不显示在日历。
3. 同标题两条考试日程分别保留。考试通知找到唯一原日程时并列保存事件、更新原 revision；匹配两条时零写入并询问。
4. 表结构候选点击拒绝、双击确认、状态变 stale 后重审；不在 AI 文本中直接信任“我确认了”。
5. 两个内容在同一自定义表删除批次中；删除后 29 天恢复原 ID，30 天不恢复，默认表不能删除。
6. 迁移内容计数、正文、待办/日程 ID 和原有 links 哈希相符；全局知识记录数和确认状态不变。
