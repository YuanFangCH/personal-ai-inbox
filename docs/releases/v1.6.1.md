# 懒狗秘书 v1.6.1 Android 预览版

本版改进秘书对话的实时反馈：模型准备、等待、思考、工具调用和回复生成过程会显示在助手回复上方；工具真正派发后会立即刷新，已有回执时显示对应工具已返回。完成、停止或失败的回复只保留默认折叠的「运行过程」入口，展开后仍可从本机会话记录回看，不新增数据库字段。

界面强调色同步调整为更清晰的浅蓝主题，正文和背景保持原有层级。浅色、深色、窄屏和 1.5 倍字体仍使用同一套主题与布局规则。

发布资产只包含 Android 通用 APK 和 `SHA256SUMS.txt`，不包含新的 Windows 或平板资产。

## 兼容与升级

- 支持 Android 7.0（API 24）及以上，目标 API 36。
- 继续使用自 v1.1.4 起的长期 Android 发布证书，可从 `v1.6.0+14` 覆盖安装。
- 升级不会主动删除表、内容、会话、附件或普通设置。
