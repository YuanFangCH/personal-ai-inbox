# 个人 AI 收件箱 v1.1.0 预发布

这是第二个 GitHub 预发布版本。相较 `v1.0.0`，本版重点重做了日历工作区、事件与待办展示，以及手动新建流程。当前包仍适合测试与开发验证，不建议作为正式生产版本分发。

## 主要更新

- 日历升级为统一工作区，底部可切换“日程 / 我的一天 / 待办”，主导航移除重复待办入口。
- 日程支持年、月、周、日、日程列表五种模式，进入默认显示详细月视图，并可切换概要模式。
- 事件和带截止时间的待办共同进入日期格、周/日时间轴和日程列表；基础重复规则会正确投影到这些视图。
- “我的一天”跟随日历选中日期，展示事件、截止待办和逾期待办摘要。
- 事件与待办改用快速新建，自动带入当前选中日期和当前时间；展开更多设置后可编辑重复、所属事项、标签、状态和正文。
- 完成手机、平板、Windows 和 Web 响应式适配，补充高字体与多尺寸回归。

## 安装与升级

### Android

1. 下载 APK 后允许当前浏览器或文件管理器安装未知来源应用。
2. 安装并打开“个人 AI 收件箱”。
3. 在设置页填写 OpenAI 兼容的 `Base URL`、模型名和 API Key。

本版继续使用 Android Debug 证书，版本号为 `1.1.0`、版本代码为 `2`，可以直接覆盖安装同一证书签名的 `v1.0.0` 测试包。以后切换到正式签名证书时，需要先卸载旧测试包。

### Windows 11 x64

安装版：

1. 运行 `personal-ai-inbox-v1.1.0-windows-x64-setup.exe`。
2. 按向导安装到当前用户目录。
3. 从开始菜单启动；安装时可选择创建桌面快捷方式。

便携版：

1. 解压 `personal-ai-inbox-v1.1.0-windows-x64-portable.zip` 到固定目录。
2. 双击 `personal_ai_inbox.exe`。
3. 不要只复制 EXE，DLL 和 `data/` 目录必须与 EXE 保持在同一目录结构。

Windows 包当前未进行代码签名，SmartScreen 可能显示“未知发布者”。

### 数据兼容

本次没有修改 Markdown frontmatter 或同步协议。升级不会迁移或重写现有成果，已有 `vault/` 和 SQLite 索引可以直接继续使用。

- Android 和 Windows 包均未使用正式发布签名。

- API Key 只保存在系统安全存储中，不进入安装包、Markdown 或仓库。
- 图片在配置模型后默认允许出网，客户端会处理尺寸与 EXIF，但不会自动识别图片内容是否敏感。
