# 懒狗秘书 v1.6.3 Android 手机预览版

本版将本机 `AGENTS.md` 作为秘书长期指令文件。用户可在设置页编辑、导出和撤销；完全体模式下，用户明确要求修改长期规则时，Agent 可在版本校验与授权检查通过后更新文件。指令不会进入会话记录或同步。

旧全局知识不再参与检索、写入或同步。用户可在设置中预览旧知识、候选及关联冲突，确认后校验归档 ZIP，再从活动库清理；归档不会自动写入 `AGENTS.md`。

最低 Android 7.0（API 24），目标 API 36。预览 APK 使用项目长期签名，支持从 `v1.6.2+16` 覆盖升级。发布状态和 API 35 模拟器验收结果见 `test-results/phone-release-v1.6.3/VALIDATION.md`。
