# 懒狗秘书 v1.4.0 Android 预览版

本版将 Android 手机端的 AI 秘书升级为 Flutter 原生单 Agent Harness：取消应用层累计任务预算，补齐完全权限下的全量表数据能力，并保留可恢复任务、真实工具回执、版本校验和 Android 生命周期保护。发布资产只包含 Android 通用 APK 和 `SHA256SUMS.txt`；不包含新的 Windows 资产。

## 主要变化

- 所有权限模式取消累计 2 小时/240 次请求预算和追加额度；用量账本只记录请求、工具和活动时长，不再产生 `exhausted` 或阻断任务。
- Agent 循环持续执行“模型请求 → 工具批次 → 真实回执 → 再请求”，直到完成、明确失败、用户停止或进入真实等待态。
- 只读工具可并行执行，最多 10 个；写工具作为独占屏障串行执行，工具结果按模型调用顺序保存。
- 相同工具在 3、5、8 次时只注入纠偏提醒，不再因固定重复次数硬暂停整个任务。
- 上下文达到容量边界时先裁剪旧工具正文，再保存结构化检查点；完整工具调用/结果对不会被拆开，压缩失败不会静默切换 transcript。
- 任务检查点升级为 v3；旧 v1/v2 用量保留，因旧预算耗尽而暂停的任务升级后重新排队，`needsReview` 仍要求人工核对。
- 完全权限可读取和修改任意表、字段、正文、内容、回收站批次、收纳目标及全局知识；新增回收站列表、预览、恢复和收纳目标读取工具。
- 完全权限允许省略 revision 与幂等键：执行器按 tool call ID 生成幂等键，并在提交前读取最新 revision 做 CAS；陈旧版本返回结构化 `stale`，由 Agent 继续处理。
- 查重冲突在完全权限下自动新建独立条目并标记“待核对”；标准模式仍保留冲突询问。
- Android 前台服务、后台恢复、用户停止和既有表/日历/知识入口保持不变。

- Android 15 / API 35 AVD：`table_ai_android_test.dart` 1/1，覆盖 AI 表内写入、结构确认、日程创建与改期、删表和重启恢复。
- 真实 DeepSeek Android AVD：1/1，覆盖连接 `connection-ok`、普通回复、`table_list` 三默认表读取，以及完全权限 `content_create` 写入事件表和本地读回。
- Release APK 由 Android 专用流水线构建，并校验 `versionName=1.4.0`、`versionCode=11`、minSdk 24、targetSdk 36、必要权限及长期 Android 发布证书。

## 安装与兼容

- 支持 Android 7.0（API 24）及以上。
- 本版继续使用 v1.1.4 起的长期 Android 发布证书，可从 v1.1.4 及之后的同证书版本覆盖安装。
- v1.1.3 及更早版本不保证直接覆盖安装。升级前请备份应用数据和完整 Markdown 主库，再按应用内迁移门确认。
- API Key 只保存在本机安全存储；安装包和仓库不包含模型凭据。

## 验证边界

- 本版只验收 Android 手机侧；未新增 Windows 资产，也未补跑平板或 Windows UI 验收。
- A01–A30、A34–A35 的遗留主机审计组合继续保留为后续工作，不以本版手机验收替代。
- 未执行全量测试，未操作真实用户资料。
- OneDrive/百度网盘跨端同步和到点提醒仍未接入。
