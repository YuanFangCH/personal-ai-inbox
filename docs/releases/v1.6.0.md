# 懒狗秘书 v1.6.0 Android 预览版

本版新增 Android 多表桌面小组件。一个桌面卡片可以同时显示作业、考试、待办等多张逻辑表，并按表配置类型、状态、日期范围、排序、条数和自定义字段。发布资产只包含 Android 通用 APK 和 `SHA256SUMS.txt`，不包含新的 Windows 或平板资产。

## 小组件

- 从「设置 → 桌面小组件」创建、编辑、预览、归档和恢复逻辑卡片。
- 支持指定表和全部表两种来源；已保存的表或字段失效时跳过并提示，恢复后自动重新出现。
- 普通模式下秘书只能读取卡片配置；完全权限且允许 `appSettingsUpdate` 时可创建、替换、归档和恢复逻辑卡片。
- AI 不操作启动器实例；添加、移动和移除实例仍由用户完成。
- 同一逻辑卡片可以绑定多个桌面实例，修改一次配置后一起刷新。
- 标题点击打开对应表，条目点击打开现有编辑页；已移动条目打开当前位置，已删除条目回到表列表。
- API 31 及以上的大尺寸实例使用滚动列表；4×2 显示短列表，2×2 显示多表摘要。API 24–30 使用固定行和「打开 App 查看全部」。
- 支持系统、浅色和深色主题，以及仅标题、标题和字段、全部隐藏三档人工隐私设置。
- 卡片保存的数据只包含显示用短文本和稳定 ID，不包含 Markdown 正文、附件、会话或凭据。
- 更新 PDF 读取依赖，修复上游 PDFium 下载路径变化导致的冷构建失败；文档、表格和 PDF 的本机文本提取链路继续保留。

## 缓存与隐私

- App 不在后台计算跨天日期。关闭或被杀后，桌面显示上次快照并标注数据日期；重开或回到前台时重新计算。
- 卡片配置和快照保存在 Android 私有 `noBackupFilesDir`，不进入成果同步、设置导出或系统备份。
- 普通模式不会向会话暴露卡片配置写权限；完全权限的执行、恢复和实际提交都会重新检查当前权限及表读取范围。

## 验证

- Android 手机适用秘书矩阵：50/50，50 个唯一用例，用时约 4 分 06 秒。
- 900 秒本地响应业务长测：实际 921 秒，47 条唯一写入与读回、219 次模型请求；切后台、锁屏 12 秒、唤醒、重开 App 和最终流式答复通过。
- 小组件主机定向：33/33，覆盖投影、隐私、原子存储、CAS/幂等、权限复核、刷新、桥接和秘书工具。
- Android 15 / API 35 模拟器：多表、自定义字段和日期筛选；2×2、4×2、4×4 和滚动；深色；同一卡片两个实例同步更新；不同卡片独立绑定；取消固定；归档恢复；杀进程后条目冷启动进入正确编辑页。
- 从 `v1.5.1+13` 同 Debug 签名覆盖到 `v1.6.0+14`，合成表、17 条条目和含 2 条消息的会话均保留。

## 安装与兼容

- 支持 Android 7.0（API 24）及以上。
- 正式预览版继续使用 v1.1.4 起的长期 Android 发布证书，可从相同证书版本覆盖安装。
- 升级不会主动删除表、内容、会话、附件或普通设置。
- API Key 仍只保存在本机安全存储；桌面小组件配置不参与设备间同步。
