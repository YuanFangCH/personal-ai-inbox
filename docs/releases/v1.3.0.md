# 懒狗秘书 v1.3.0 Android 预览版

本版是 Android 手机优先的预发布版本，集中交付专用秘书 Agent、表与笔记、应用内权限和可恢复后台任务。发布资产只包含 Android 通用 APK 和 `SHA256SUMS.txt`；不包含新的 Windows 资产。

## 主要变化

- 秘书支持标准模式与完全权限模式，可在应用内操作表、字段、内容和全局知识，并保留必要的版本、权限和撤权检查。
- 正式自动录入增加写前查重、幂等复用、兼容补充和冲突暂停；相同标题不会仅因标题相同被误判为同一事项。
- 秘书任务支持多步工具执行、真实写入与检查回执、两小时/240 次请求额度、分批继续、运行中补充指令和中断恢复。
- Android 增加前台服务和通知权限处理；Activity 重建、进程终止、最近任务划掉、服务中断、服务限制和超时后均可显式继续原任务。
- 秘书页常驻 AppShell，切换首页、日历或表会保留当前会话、草稿和生成状态。
- 表、首页、日历和全局知识入口继续使用本地 Markdown 与 SQLite 索引；旧格式资料仍需在应用内确认迁移。

## 手机验证

- 既有最终设备候选 manifest `c283f93b19703686ab7caa0da802e43ff8bb5c557051156c070c9e94f07f49bd` 在 Android API 35 手机模拟器通过 50/50 秘书矩阵、A31–A33 恢复场景和 900 秒生产业务长测；长测完成 47 条唯一写入与回执核对。
- 2026-11-08 新增手机回归通过：`conversation_lifecycle_test.dart` 4/4；`conversation_large_history_ui_test.dart` 1/1，覆盖 220 条历史、流式长回复、停止后保留草稿。
- 新增“最近任务划掉”两阶段设备场景通过：真实滑动移除任务后冷启动不自动发送请求，显式继续复用原任务、条目和写入回执，内容只写入一次。
- Release APK 由 Android 专用流水线重新构建，并校验 `versionName=1.3.0`、`versionCode=10`、minSdk 24、targetSdk 36、必要权限及长期 Android 发布证书。

## 安装与兼容

- 支持 Android 7.0（API 24）及以上。
- 本版继续使用 v1.1.4 起的长期 Android 发布证书，可从 v1.1.4 及之后的同证书版本覆盖安装。
- v1.1.3 及更早版本不保证直接覆盖安装。升级前请备份应用数据和完整 Markdown 主库，再按应用内迁移门确认。
- API Key 只保存在本机安全存储；安装包和仓库不包含模型凭据。

## 验证边界

- 本版只验收 Android 手机侧；未新增 Windows 资产，也未补跑平板或 Windows UI 验收。
- A01–A30、A34–A35 的遗留主机审计组合继续保留为后续工作，不以本版手机验收替代。
- 未执行全量测试，未操作真实用户资料。
- OneDrive/百度网盘跨端同步仍未接入。
