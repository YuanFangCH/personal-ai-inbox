# 懒狗秘书 v1.6.2 Android 手机预览版

本预览版改进首页和桌面小组件的时间排序、跨表时间轴、简洁/详细显示和翻页体验。首页、表详情和小组件统一把待办截止时间、日程开始时间和事件发生时间按升序展示，无业务时间的条目放在最后。

Android 12 及以上各尺寸小组件使用标准 StackView，支持上下大滑动和前后页按钮；每页使用不透明浅色或深色卡片，不再显示卡片标题、表标题或冗余条数。桌面隐私可切换“简洁（仅标题）”“详细（标题和时间）”或全部隐藏。Android 7–11 保留固定行和点按翻页。设置、卡片 ID、桌面绑定与旧快照格式保持兼容。

最低 Android 7.0（API 24），目标 API 36。请从 GitHub `phone-v1.6.2` 预览页下载通用 APK，并用 `SHA256SUMS.txt` 校验。此前版本从 v1.6.1 起使用固定长期签名，可覆盖升级；升级后核对本机数据与桌面卡片。

API 35 模拟器已完成 2×2、4×2、大尺寸、深浅色、大字体、双向滑动、按钮翻页、冷进程单次点击、多实例隔离和尺寸调整重置验收；详见 `test-results/phone-release-v1.6.2/VALIDATION.md`。荣耀 90 与 API 24–30 固定行仍缺设备验证。

本版已经发布为 [phone-v1.6.2](https://github.com/YuanFangCH/personal-ai-inbox/releases/tag/phone-v1.6.2)。main CI `43803812848` 与 Android Release `43805072945` 均成功；公开 APK SHA-256 为 `2488f15d442cd4cd0661bf55ce428167a9f3992b412fd59074c29ca620f59863`。API 35 升级 AVD 已从 `v1.6.1+15` 覆盖安装，并保留合成 Markdown、会话、表和桌面绑定。
