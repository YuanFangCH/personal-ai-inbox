# 个人 AI 收件箱 v1.1.2 预发布

这是以测试与可靠性为主的维护性预发布版本。新增 100 条真实端到端场景并在手机、平板和 Windows 三端执行，修复手机高字体下的状态标签溢出；成果格式、同步协议与数据库结构不变。

## 发布资产

| 平台 | 文件 | 说明 |
|---|---|---|
| Android | `personal-ai-inbox-v1.1.2-android.apk` | Android 7.0 及以上通用 APK |
| Windows x64 | `personal-ai-inbox-v1.1.2-windows-x64-setup.exe` | Windows 11 x64 安装包 |
| Windows x64 | `personal-ai-inbox-v1.1.2-windows-x64-portable.zip` | Windows 11 x64 便携包 |
| 全部 | `SHA256SUMS.txt` | 发布资产的 SHA-256 校验值 |

## 主要变更

- 新增 100 条多步骤真实端到端场景，覆盖捕获解析、待整理、日历五模式、事项聚合、知识检索、AI 对话与自动记录、会话失败与停止、同步冲突裁决、冷启动持久化、设置和崩溃恢复。
- 场景按 50 手机 / 25 平板 / 25 Windows 分配，由同一份数据驱动三端，避免平台间漂移。
- 实测结果：Pixel 6 AVD 50/50、2560×1600 平板 AVD 25/25、Windows 桌面 25/25，全部通过。
- 修复手机 1.15x 字体下待确认状态标签横向溢出 7.1px 的问题，并补充回归测试。
- `AppRuntime.bootstrap` 增加可选同步通道注入，便于用脚本通道验证冲突与裁决；默认行为不变。
- 主机回归扩展到 376 项，新增矩阵完整性、状态标签和主机冒烟测试。

## 数据兼容

本版没有修改 Markdown frontmatter、成果类型、同步协议或数据库 schema（索引库 `user_version=3`、会话库 `user_version=1`）。现有 `vault/`、SQLite 索引、设置和本地 AI 会话可以直接继续使用，可直接覆盖安装。

## 验证范围

- Dart 格式检查、`flutter analyze` 通过。
- 主机全量测试 376/376 通过。
- 三端真实端到端矩阵：手机 50/50、平板 25/25、Windows 25/25。
- 发布工作流会再次执行格式、静态分析、完整主机回归、Android/Windows release 构建、APK 元数据与证书校验、Windows 安装/卸载冒烟和便携包校验。

## 当前限制

- Android 继续使用 Debug 证书，Windows 包未进行代码签名；系统可能提示未知来源或 SmartScreen。
- OneDrive OAuth、百度网盘归档、本地通知和真实跨端同步仍未完成。
- 端到端矩阵使用脚本化模型与内存同步通道，不代表真实网关时延、限流或线上抽取准确率；真机后台策略、通知和第三方图片分享仍需设备验收。
