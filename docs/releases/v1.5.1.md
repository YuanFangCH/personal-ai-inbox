# 懒狗秘书 v1.5.1 Android 补丁预览版

本版修复中断任务在 AI 页面反复显示“任务中断，等待核对”、点击“已核对，继续”后仍无法推进的问题。发布资产只包含 Android 通用 APK 和 `SHA256SUMS.txt`，不包含新的 Windows 资产。

## 修复内容

- 当最新工具回合因工具调用参数或工具结果过大而无法完整装入模型上下文窗口时，不再直接阻断任务。
- 上下文压缩会回退到本地安全摘要，保留原始目标、补充要求、对象 ID/版本、操作回执、待核对冲突和分页读取信息。
- 安全摘要标记 `latest_tool_round_compacted`，让模型知道完整工具参数正文已被裁剪，并按需缩小范围重新读取。
- 只要压缩结果低于模型上下文硬上限就允许继续，不再因为额外的 10% 缩小余量未达到而反复暂停。
- 完整原始工具 transcript 继续保存在本机，不会因发送摘要而删除审计记录。
- 用户点击“已核对，继续”后可以重新派发模型请求，不再每次回到相同核对状态。

- 支持 Android 7.0（API 24）及以上。
- 继续使用 v1.1.4 起的长期 Android 发布证书，可从 `v1.5.0+12` 直接覆盖安装。
- 升级不会删除表、内容、会话、附件或普通设置。
- API Key 仍只保存在本机安全存储中；本补丁不改变凭据和系统权限边界。
