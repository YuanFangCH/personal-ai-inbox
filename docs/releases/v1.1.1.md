# 个人 AI 收件箱 v1.1.1 bugfix 候选

这是维护性升级后的 bugfix 候选版本，尚未创建 Git 标签或发布 GitHub Release。本版以模块化、可测试和可维护为主，同时修复 Android 设备矩阵发现的日历快速新建面板瞬态溢出。

## 主要变更

- 本地核心拆分为端配置、成果库、捕获、会话和同步模块，外部使用不可变快照和稳定接口。
- 成果写入统一经过成果库模块；捕获和自动记录不能绕过 Markdown/SQLite 不变量。
- 应用控制器降为迁移期兼容 facade，不再承载 Markdown、SQLite、SSE、冲突和重试实现。
- 同步报告增加结构化失败列表，保留对象、阶段、错误码、可重试性和时间。
- 日历视图、快速新建和对话页拆分为较小的组件文件。
- 增加架构依赖测试、模块契约测试和同步失败测试。
- 修复 Android 390x844 手机视口下，关闭快速新建面板时底部溢出 52px 的问题。

## 数据兼容

本版没有修改 Markdown frontmatter、成果类型或同步协议。现有 `vault/`、SQLite 索引和本地 AI 会话可以直接继续使用。

## 验证范围

- Dart 格式和 `flutter analyze` 通过。
- 完整主机测试通过。
- Android release、Windows release 和 Web release 构建通过。
- Windows 原生 integration smoke 通过。
- Android phone/tablet AVD smoke 通过。
- Android UI 设备矩阵 `100/100` 通过。

## 当前限制

- 本版是本地 bugfix 候选，未创建 `v1.1.1` 标签，也没有上传 GitHub Release。
- Android 继续使用 Debug 证书，Windows 包未进行代码签名。
- OneDrive OAuth、百度网盘归档、本地通知和真实跨端同步仍未完成。
- 应用控制器仍作为迁移期兼容 facade 存在，后续页面迁移完成后删除。
