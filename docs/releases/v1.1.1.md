# 个人 AI 收件箱 v1.1.1 预发布

这是维护性升级后的 bugfix 预发布版本。本版以模块化、可测试和可维护为主，同时修复 Android 设备矩阵发现的日历快速新建面板瞬态溢出。

## 发布资产

| 平台 | 文件 | 说明 |
|---|---|---|
| Android | `personal-ai-inbox-v1.1.1-android.apk` | Android 7.0 及以上通用 APK |
| Windows x64 | `personal-ai-inbox-v1.1.1-windows-x64-setup.exe` | Windows 11 x64 安装包 |
| Windows x64 | `personal-ai-inbox-v1.1.1-windows-x64-portable.zip` | Windows 11 x64 便携包 |
| 全部 | `SHA256SUMS.txt` | 发布资产的 SHA-256 校验值 |

## 主要变更

- 本地核心拆分为端配置、成果库、捕获、会话和同步模块，外部使用不可变快照和稳定接口。
- 成果写入统一经过成果库模块；捕获和自动记录不能绕过 Markdown/SQLite 不变量。
- 应用控制器降为迁移期兼容 facade，不再承载 Markdown、SQLite、SSE、冲突和重试实现。
- 同步报告增加结构化失败列表，保留对象、阶段、错误码、可重试性和时间。
- 日历视图、快速新建和对话页拆分为较小的组件文件。
- 增加架构依赖测试、模块契约测试和同步失败测试。
- 修复 Android 390x844 手机视口下，关闭快速新建面板时底部溢出 52px 的问题。

## 数据兼容

本版没有修改 Markdown frontmatter、成果类型或同步协议。现有 `vault/`、SQLite 索引和本地 AI 会话可以直接继续使用。
