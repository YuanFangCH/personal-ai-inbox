# 懒狗秘书 v1.1.4 预览版

本版修复 Android 预览包签名在不同构建之间变化的问题。Android APK 自本版起使用固定的长期发布证书；Windows 包仍未进行代码签名。

**兼容说明：** GitHub `v1.1.1` 及之前预览 APK 使用不一致的临时 Debug 证书。此 APK 不能直接覆盖安装到这些旧版本上。需要先备份旧版数据，再卸载旧版安装；用户手机数据迁移单独评估。v1.1.4 及以后使用相同发布证书的版本可以覆盖升级。
