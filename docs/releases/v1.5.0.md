# 懒狗秘书 v1.5.0 Android 预览版

本版新增设置页“完全体模式”，把 Android 手机端 AI 秘书升级为可全局覆盖的应用内完全 Agent。开关默认关闭；开启后立即作用于全部现有和新会话，关闭后恢复每个会话原本保存的权限策略。发布资产只包含 Android 通用 APK 和 `SHA256SUMS.txt`，不包含新的 Windows 资产。

## 主要变化

- 设置页新增设备级“完全体模式”开关，权限面板在该模式下锁定，只能回到设置页关闭。
- 完全体模式取消应用层累计请求、活动时长、历史消息窗口、本地检索批次、附件数量和附件处理的固定产品上限。
- 请求按模型声明的上下文容量动态装载；超出时保留工具调用与回执配对，并压缩已结算历史。
- 模型因输出长度结束时自动续写并合并到同一答复；正常结束、工具调用、达到输出上限和协议中断分别处理。
- 网络、流空闲、请求超时、429 和可恢复服务错误改为无限退避重试，退避上限 60 秒；鉴权、欠费、配置错误和用户停止仍终止。
- 启动时恢复安全检查点：确定未执行步骤继续，已有回执复用；副作用状态不确定时只核对日志和本地状态，不盲目重复写入。
- 完全体模式可管理任意表、字段、正文、内容、全局知识、整段会话、附件和普通界面设置，并支持会话与附件 30 天本机回收站。
- API Key、模型端点和名称、图片出网、能力覆盖、权限策略、完全体开关本身及导入/导出/恢复默认继续受保护；单条消息、隐藏推理和工具回执不可改写。
- 文本、PDF、DOCX、XLSX、CSV、Markdown 和压缩包可进入本机附件处理；未知二进制保留名称、类型、大小、哈希和可读元数据。
- 不新增互联网搜索，不授予 OS 文件、终端、Root、系统控制或凭据访问权限。

## 安装与兼容

- 支持 Android 7.0（API 24）及以上。
- 本版继续使用 v1.1.4 起的长期 Android 发布证书，可从 v1.1.4 及之后的同证书版本覆盖安装。
- v1.1.3 及更早版本不保证直接覆盖安装。升级前请备份应用数据和完整 Markdown 主库，再按应用内迁移门确认。
- API Key 只保存在本机安全存储；安装包和仓库不包含模型凭据。升级不会自动开启完全体模式。

## 验证边界

- 50 例矩阵和 900 秒长测使用本地脚本化模型；真实模型只覆盖普通答复和一次 `table_list` 工具往返。
- 本版只验收 Android 手机侧；未新增 Windows 资产，也未补跑平板、Windows 或物理 Android 设备验收。
- 未执行全量 Flutter 测试，未操作真实用户资料。
- 完全体模式不能消除模型硬限额、网络不可用、磁盘耗尽、设备重启或厂商强制停止等物理边界。
- OneDrive/百度网盘跨端同步和到点提醒仍未接入。
