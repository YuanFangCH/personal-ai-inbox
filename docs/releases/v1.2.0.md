# 懒狗秘书 v1.2.0 预览版

本预览版将信息组织方式改为笔记式表：表既能直接记录正文，也能容纳待办、日程、事件和普通笔记。AI 对话可按表查找并维护内容；主页面切换期间，秘书会话继续保留。

## 更新内容

- **表与笔记**：提供待办、日程、事件三个不可删除的默认收纳表；可创建自定义表，并在表内混合记录普通笔记、普通知识、待办、日程和事件。
- **自定义字段**：支持文本、数字、日期时间、单选、多选和勾选字段；表内容可在表之间移动。
- **首页与日历**：首页保留已有区块，支持添加、排序表模块，默认显示五行并可展开。日历是只读显示投影，聚合各表中明确创建的待办、日程和带发生时间的事件，并支持按表筛选；仅有时间标签的普通笔记不会进入日历。
- **AI 表内操作**：AI 按表搜索并执行授权范围内的内容新增、修改、删除和跨表移动，通常无需逐项确认。新增/删除表及字段定义变更通过对话内确认卡审批。全局知识仍独立管理，改动需要确认；普通知识作为普通笔记收纳进表。
- **旧事项迁移**：应用提供迁移预检、备份及确认入口，将旧事项迁成表并保留正文与可迁移的关联待办、事件；旧源文件保持原样。真实资料尚未在本轮验证。
- **秘书页状态保留**：手机保留底部导航，桌面保留应用侧栏；秘书页在主页面切换时继续保留当前会话、草稿、附件和阅读位置，回复生成不中断。历史对话、新对话与系统分享目标在秘书页内切换。

## 升级与已知限制

- **升级前必须备份**：先备份旧版应用数据目录和完整 Markdown 主库，并确认备份可读。迁移会生成新格式副本并保留旧源，但不替代用户自己的升级前备份；只在目标数据副本上首次演练。发现旧资料时，按应用内只读预检与确认步骤执行，不要手工删除旧数据。
- 本轮没有完成含真实用户资料的覆盖升级或迁移验收。Android 模拟器上的秘书页“发送→切日历→返回”、草稿/附件往返等交互验收缺口仍存在；CI 构建通过不代表这些交互已通过。
- OneDrive/百度网盘跨设备表同步、云端备份与本地通知尚未接入。新表格式仍是端内本地能力，不能据此假设表数据已同步到其他设备。
- Windows 包未进行代码签名，首次运行可能出现 SmartScreen 警告。
- Android APK 应延续 v1.1.4 起使用的长期发布证书；v1.1.3 及更早的 APK 签名不保证兼容直接覆盖安装。安装前先备份数据。
