# 懒狗秘书 v1.1.5 预览版

本版集中交付 DeepSeek 风格的 AI 对话与首页改版，并优化输入交互和页面布局。Android APK 延续 v1.1.4 起使用的长期发布证书。

## 更新内容

- 重做首页信息呈现，移除顶部捕获区和统计卡，日程、待办、最近知识直接平铺展示。
- 改进 AI 对话布局与动效，完善桌面空态过渡、历史导航、长消息阅读和 Markdown 代码/表格显示。
- 修复窄高窗口溢出、桌面输入区遮挡消息、调整窗口宽度后输入焦点丢失、Enter/Shift+Enter 与中文输入组合、语音停止竞态等问题。
- 补充待办完成/失败反馈、知识加载重试、减少动态效果支持，并收敛日历重复导航。

## 已知限制
- Windows 安装包未进行代码签名。v1.1.3 及更早 Android 预览包使用的签名不保证与本版兼容；安装前应先备份旧版数据并查阅 v1.1.4 迁移说明。
