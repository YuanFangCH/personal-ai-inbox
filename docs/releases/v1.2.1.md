# 懒狗秘书 v1.2.1 预览版

本版包含 v1.2.0 后完成的迁移修复、旧源清理和真实模型工具调用修复。

## 修复与改进

- 修复 DeepSeek 聊天 HTTP 400：表工具使用 OpenAI 兼容的下划线函数名，本地操作与历史记录保持兼容。
- 修复过去已有日期的旧安排、旧删除记录导致迁移阻断的问题。
- 修复迁移完成后正常编辑内容引起的再次启动阻断，保留用户后续修改。
- 迁移完成后先校验备份及源文件哈希，再清理非全局旧格式活动源件；保留迁移备份、完成凭据和全局知识，中断可续跑。清理后旧源入口消失，回退旧版需要显式还原备份。
- 秘书在应用主页面之间切换时继续保留会话、草稿与回复生成状态。

## 验证与边界

- 修复代码已通过 Android 15 手机 50/50、平板 25/25 确定性场景，以及真实 DeepSeek 连接、普通回复、只读工具往返和首页往返冒烟。该验收使用上一版号的同代码签名 APK；本次升级版本号后由发布流水线重新构建。
- 迁移修复已在真实设备完成迁移、旧源清理及冷启动验证；工具名修复后的用户真实手机覆盖安装仍待无线调试恢复。
- Windows 启动及其 25 个交互场景未验收；安装器/便携包构建检查不代表交互通过。
- 发布前扫描全部本地 Git 引用及待发布源码，未发现规则命中的 API Key、访问令牌或私钥。测试凭据与设备数据不进入分发资产；扫描不能作为绝对无秘密的保证。
- 本次 CI 执行迁移、runtime、聊天工具与秘书 UI 的定向回归，复用既有模拟器证据；未执行全量测试。

## 升级与下载

升级前备份应用数据和完整 Markdown 主库，再按应用内迁移门确认。迁移备份不会替代用户自行保存的升级前备份。v1.1.4 起沿用长期 Android 发布证书，v1.1.3 及更早版本不保证直接覆盖安装。

发布资产为 Android 通用 APK、Windows x64 安装包、Windows x64 便携 ZIP 与 SHA256SUMS.txt。下载后请校验 SHA-256。Android 7.0 及以上可安装；Windows 包未代码签名。

OneDrive/百度网盘跨端同步、云端备份和本地通知尚未接入。
