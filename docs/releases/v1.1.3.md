# 懒狗秘书 v1.1.3 预览版

本版将原收件箱升级为 AI 秘书对话，并完成手机、平板和 Windows 三端共 100 例验收。此版本为预览版，Android APK 使用 Debug 证书，Windows 包未进行代码签名。

## 发布资产

| 平台 | 文件 | 说明 |
|---|---|---|
| Android | `personal-ai-inbox-v1.1.3-android.apk` | Android 7.0 及以上通用 APK |
| Windows x64 | `personal-ai-inbox-v1.1.3-windows-x64-setup.exe` | Windows 11 x64 安装包 |
| Windows x64 | `personal-ai-inbox-v1.1.3-windows-x64-portable.zip` | Windows 11 x64 便携包 |
| 全部 | `SHA256SUMS.txt` | 发布资产的 SHA-256 校验值 |

## 主要变更

- 收件箱改为 AI 秘书对话；进入时创建新对话，历史会话从侧栏管理，待处理独立成页。
- 提供读取、新增、修改与删除三组会话权限。新会话继承总设置默认值，顶部权限控件只改当前会话；默认全部开启。
- AI 可读取成果与其他会话；可按请求新增普通成果，按权限修改和删除事项、待办、日历事件与知识成果，并展示操作结果及支持撤销。其他会话仅可读取。
- 新增全局基础知识库。AI 可按需检索已确认事实并遵循读取权限；知识新增、修改和删除均需人工确认。
- 增加本地文件文字提取、语音转文字输入和 AI 回复朗读；支持的模型端点可启用深度思考。当前 Chat Completions 接口未声明内置联网能力，联网按钮禁用。
- 应用显示名称改为“懒狗秘书”，默认 AI 角色为秘书型助理。

## 数据与限制

- Markdown 仍为成果正文权威副本；会话、消息和未确认知识候选保留在本机。当前版本未接通 OneDrive，因此不能提供真实手机、平板和 Windows 间云端同步。
- 文件在本机提取文本后发送给模型，不上传原始文件；扫描版 PDF 不执行 OCR。语音依赖系统语音服务，矩阵使用受控替身，不代表真机麦克风和扬声器验收。
- 联网搜索不可用；真实模型 Key 联调、OneDrive/OAuth、百度网盘归档、本地通知、真机音频、签名和生产数据升级恢复仍待后续验证。
- Android 使用 Debug 签名，Windows 包未代码签名，系统可能提示未知来源或 SmartScreen。
