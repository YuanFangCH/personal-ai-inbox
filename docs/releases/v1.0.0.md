# 个人 AI 收件箱 v1.0.0 预发布

这是项目的首个 GitHub 预发布版本，用于体验本地优先的 Markdown 成果库、AI 多会话和受控自动记录。当前包适合测试与开发验证，不建议作为正式生产版本分发。

## 下载资产

| 平台 | 文件 | 说明 |
|---|---|---|
| Android | `personal-ai-inbox-v1.0.0-android.apk` | Android 7.0（API 24）及以上，通用 APK |
| Windows 11 x64 | `personal-ai-inbox-v1.0.0-windows-x64-setup.exe` | 按当前用户安装，无需管理员权限 |
| Windows 11 x64 | `personal-ai-inbox-v1.0.0-windows-x64-portable.zip` | 解压后运行，不写安装项 |
| 全部 | `SHA256SUMS.txt` | 发布资产的 SHA-256 校验值 |

## 安装

### Android

1. 下载 APK 后允许当前浏览器或文件管理器安装未知来源应用。
2. 安装并打开“个人 AI 收件箱”。
3. 在设置页填写 OpenAI 兼容的 `Base URL`、模型名和 API Key。

当前 APK 使用 Android Debug 证书签名。它可以覆盖安装同一证书签名的测试包，但不能直接升级到以后使用正式证书签名的版本。

### Windows 11 x64

安装版：

1. 运行 `personal-ai-inbox-v1.0.0-windows-x64-setup.exe`。
2. 按向导安装到当前用户目录。
3. 从开始菜单启动；安装时可选择创建桌面快捷方式。

便携版：

1. 解压 `personal-ai-inbox-v1.0.0-windows-x64-portable.zip` 到固定目录。
2. 双击 `personal_ai_inbox.exe`。
3. 不要只复制 EXE，DLL 和 `data/` 目录必须与 EXE 保持在同一目录结构。

Windows 包当前未进行代码签名，SmartScreen 可能显示“未知发布者”。首次运行后，请在设置页配置模型和 API Key。

## 校验

PowerShell：

```powershell
Get-FileHash -Algorithm SHA256 .\personal-ai-inbox-v1.0.0-android.apk
Get-FileHash -Algorithm SHA256 .\personal-ai-inbox-v1.0.0-windows-x64-setup.exe
Get-FileHash -Algorithm SHA256 .\personal-ai-inbox-v1.0.0-windows-x64-portable.zip
```

将输出与 `SHA256SUMS.txt` 对照。

## 当前限制

- Android 和 Windows 包均未使用正式发布签名。
- OneDrive OAuth、百度网盘归档和跨端真实同步尚未完成，同步页当前使用端内沙箱 Provider。
- 本地通知、厂商后台策略、相机完整流程和第三方图片分享仍需继续验证。
- API Key 只保存在系统安全存储中，不进入安装包、Markdown 或仓库。
- 图片在配置模型后默认允许出网，客户端会处理尺寸与 EXIF，但不会自动识别图片内容是否敏感。
