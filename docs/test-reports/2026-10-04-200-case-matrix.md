## 测试层次

| 层次 | 覆盖 |
|---|---|
| 核心解析 | 200 条全部断言成果类型、是否需复核、开始时间或截止时间 |
| Markdown/SQLite | 按设备分别写入、删除索引后从 Markdown 重建、重新同步 |
| 本地同步 | 每档首次上传全部成果，第二轮全部 unchanged，失败数为 0 |
| 前端 | 390x844、1024x768、1440x900 三档渲染；逐页切换、滚动、打开长文详情并断言无布局异常 |
| 平台构建 | Web release；Android debug/release APK；Android manifest 和签名校验 |
| 真实平台 | Windows release + Windows integration test；Android 15 模拟器 phone/tablet integration test |

## 首轮发现并修复

| 问题 | 修复 |
|---|---|
| “今晚 8 点半”生成 08:30 | 补充晚上无显式标记时的 afternoon/evening 规则 |
| “明天下午 5 点前提交”被误判为事件 | 截止词优先于事件解析 |
| “提前确认”里的“前确认”误触发截止规则 | 截止探测前排除“提前” |
| 手机 390px 下日历日格底部溢出 | 调整日格长宽比和内部间距 |
| 周日语境下“下周一”的预期日期写错 | 固定为周一 2026-10-05，与自然语言一致 |
