# 会话按首次内容创建，确认入口合并到收件箱

应用冷启动和普通重进直接停留在首页，不再自动创建或打开空白会话。用户点击“新对话”时只进入一个未持久化的输入页；只有首次发送非空文字或图片时，才创建会话、写入首条消息并按内容生成标题。未发送就退出不会留下会话记录。

启动时会删除没有任何消息的本地空会话，含用户、助手、失败或中断消息的会话全部保留。系统分享携带的文本或图片视为已有内容，仍会创建会话并自动打开。这个决定取代 ADR 0010 中“每次应用冷启动创建一个新的空白会话”的部分，其余上下文隔离、上下文裁剪和自动记录边界继续有效。

独立“确认”页不再存在。捕获确认、同步冲突、草稿和会话统一放在收件箱：待确认捕获保留按建议生成、调整和忽略，同步冲突保留本地版本或使用远端版本。这样用户只需要进入一个入口处理待办事项，也避免收件箱和确认页之间出现两套不同步的确认交互。
