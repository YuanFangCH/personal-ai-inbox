# 秘书型助理使用人工确认的全局基础知识

2026-10-20 用户追加要求：软件显示名称改为“懒狗秘书”，AI 默认担任助理或秘书；设置跨会话使用的全局知识库，保存学期起始时间、周数等基础事实，用于日期解释与计算。AI 可自动识别或按人工命令提出写入候选，但新增和修改必须由用户确认展示的内容后才生效，不能把“自动识别”或“记住这条”的原始命令当作对提取结果的最终确认。

该确认要求是 ADR 0017 普通成果直接操作规则的例外，不受模型置信度或权限默认全开取代；实现必须由本地核心执行审批检查，未确认候选不作为有效基础知识使用。选择人工确认，是因为错误的全局事实可能持续影响不同会话的回答和日期计算，代价是写入多一次确认。

三端共享还是本端共享、自动提供还是按需检索、关闭读取权限时的行为及删除确认范围仍待用户答复；本决定不提前选择存储 schema、同步范围或新增成果类型。见[补充计划](../secretary-and-global-knowledge-plan.md)。仅记录目标，业务尚未实现。
