# 秘书型助理使用人工确认的全局基础知识

2026-10-20 用户追加要求：软件显示名称改为“懒狗秘书”，AI 默认担任助理或秘书；设置跨会话使用的全局知识库，保存学期起始时间、周数等基础事实，用于日期解释与计算。AI 可自动识别或按人工命令提出候选，但新增、修改和删除均必须由用户确认展示的内容后才执行，不能把“自动识别”或“记住这条”的原始命令当作对提取结果的最终确认。

该确认要求是 ADR 0017 普通成果直接操作规则的例外，不受模型置信度或权限默认全开取代；实现必须由本地核心执行审批检查，未确认候选不作为有效基础知识使用。选择人工确认，是因为错误的全局事实可能持续影响不同会话的回答和日期计算，代价是写入多一次确认。

用户随后确认手机、平板和 Windows 共用，已确认的基础事实随成果同步；AI 只在需要时检索，受当前会话读取权限控制，关闭时不新增检索或自动注入。以既有 `knowledge` 成果承载全局范围，维持 Markdown 权威、四类成果、版本、墓碑和冲突规则；未确认候选不进入同步区。一端对内容版本完成确认后，其他端接收同版本不重复审批，冲突仍人工裁决。具体字段、审批材料与 schema 迁移待实施，见[补充计划](../secretary-and-global-knowledge-plan.md)。仅记录目标，业务尚未实现。
