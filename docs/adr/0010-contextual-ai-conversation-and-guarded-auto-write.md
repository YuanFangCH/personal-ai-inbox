# AI 对话采用本地多会话，并授权高置信自动新增成果

收件箱改为本地多会话对话界面。每次应用冷启动创建一个新的空白会话，旧会话可继续追问，但每轮只向模型发送当前会话最近 20 条消息；图片最多来自最近 4 条含图消息、总量不超过 8 张。会话、消息和图片不进入 Markdown 成果库或跨端同步，删除会话也不删除已经创建的成果。

模型可以通过 `create_result` 工具请求新建 `matter | todo | event | knowledge`。只有完整流结束、结构校验通过、置信度不低于 `0.85`、内容不敏感、日期明确且未重复时才自动创建；任何修改和删除请求均不执行。低置信、敏感、日期歧义、过去日期和重复规则进入待整理区。自动创建结果保留 10 分钟撤销窗口，成果被人工修改后不可撤销。这样保留了“AI 记录”的低摩擦入口，同时把自动副作用限制在可审计、可撤销的新增操作。

图片在配置模型后默认允许发送到云端，设置页提供默认开启的总开关。该决定取代此前“图片首次出网必须逐次确认并在出网前人工裁剪脱敏”的要求；客户端仍会自动限制尺寸、重新编码并去除 EXIF 元数据，但不保证自动识别或遮蔽图片中的敏感内容。选择这一权衡是为了满足用户明确要求的少确认操作，代价是用户必须在图片进入模型前自行控制内容。
