# Flutter 原生单 Agent Harness 取消累计任务预算

2026-11-08 用户确认：AI 功能继续采用 Flutter 本地核心，不内嵌 Termux/Node；所有权限模式取消应用层累计请求数和活动时长预算，完全权限可读取和修改任意表、字段、内容、回收站批次、收纳目标及全局知识。

运行时采用单 Agent 循环：模型请求、完整工具批次、真实回执、再次请求，直到完成、明确失败、等待用户或用户停止。只读工具可并行，写工具作为独占屏障串行执行；工具意图先持久化，结果按模型顺序结算。重复相同调用只注入纠偏提醒，不再以固定步数硬暂停。

用量账本继续记录请求数、工具数和活动时长，但仅用于状态与诊断，不产生授权额度、追加额度或 `exhausted`。任务检查点升级为 v3；旧 v1/v2 的累计用量保留，因旧额度耗尽而暂停的任务在升级后重新排队，`needsReview` 仍要求人工核对。

完全权限下精确重复仍复用，有可验证证据的同一对象仍自动补充；无法证明同一对象时新建独立条目并标记待核对，不再让整个任务停在查重冲突。版本校验、幂等键、写日志、CAS 和撤销材料仍是本地正确性边界，不因完全权限被删除。模型上下文容量、单请求超时、网络重试和 Android 系统生命周期限制仍保留，它们不是累计任务预算。

本 ADR 取代 [ADR 0024](0024-secretary-agent-permissions-and-deduplication.md) 中“2 小时或 240 次请求总额度、追加额度”和“无法判定的查重冲突暂停”部分；权限预设、预置表可删除、全局知识直接生效和可恢复任务继续有效。
