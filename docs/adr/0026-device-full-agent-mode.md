# 设备级完全体模式作为全局应用内授权覆盖层

2026-11-09 用户确认：设置页提供默认关闭的“完全体模式”开关。开关立即持久化并作用于本端全部现有及新会话；开启时统一使用应用内完全权限，关闭时撤销覆盖并恢复各会话原本保存的策略，不改写会话策略。

完全体模式取消应用层累计请求、活动时长、上下文消息数、本地检索批次、附件数量和附件处理的固定产品上限。请求按模型声明的上下文能力动态装载，超限时自动压缩或分批；输出达到单次上限时自动续写；网络、流空闲、超时、429 和可恢复服务错误无限重试并采用最长 60 秒退避。模型硬限额、网络、磁盘、系统前台限制和 Android/Windows 生命周期仍是物理边界。

完全体模式仍受本地正确性边界约束：工具意图、幂等键、CAS、写日志、撤销材料、Markdown 权威副本和本机事务不能省略。应用启动时可自动恢复能够证明没有不确定副作用的检查点；状态不确定的副作用只允许核对和复用已有回执，不盲目重放。用户主动停止仍然生效。

授权范围限于应用内数据。AI 可管理表、内容、全局知识、整段会话、附件和普通界面设置；单条消息、推理内容和工具回执保持不可改写。API Key、模型端点与名称、图片出网、权限策略、完全体开关、导入/导出/恢复默认和系统权限不属于 AI 可修改范围。

会话和附件删除进入本机 30 天回收站；整段会话可恢复。网页搜索不新增，本地检索取消累计上限但继续使用分页、分段和 coverage 回执。设置快照升级为 v6，可移植设置 v2（v1 导入默认关闭），会话数据库升级为 v7 以保存回收站条目。

选择全局覆盖而不是批量改写用户策略，是为了保证开关可逆并避免升级或开关切换扩大永久授权。代价是执行点和 UI 必须在每次模型派发、工具执行、恢复和重放前重新解析当前模式。
