# 以 MIT 协议公开发布，并使用干净公开历史

项目以 MIT 协议公开发布，许可证文本保存在根目录 `LICENSE`。公开仓库面向复用、学习和二次开发；用户自己的成果、原始素材、AI 会话、API Key、OAuth 令牌和签名材料不随源码发布。

公开版本采用一个新的单根提交，而不直接继承个人开发期间的旧提交。原因是旧历史包含设备序列号等不应公开的测试信息，且旧提交即使当前文件已删除仍可被访问。迁移前的完整本地历史保留在 `archive/pre-open-source` 分支，仅用于本机追溯，不推送。公开分支继续受 Git hooks、公开发布扫描和 GitHub 密钥扫描约束。

代价是公开历史不保留逐阶段提交记录，但换取可审计的干净发布边界；后续公开开发可以恢复正常增量提交。
