# Android 小组件使用单一可滚动时间轴

2026-11-19 用户确认放弃组件内 `StackView` 翻页和卡片套卡片的表现。Android 小组件改为一个连续的 `ListView` 时间轴，由 `RemoteViewsService` 提供行视图；页号、翻页按钮、页索引和上下翻页广播不再参与渲染。

桌面内容只投影未完成待办、普通笔记、日程和事件。业务时间统一取待办截止、日程开始和事件发生时间，按升序排列，无时间内容最后。首页表模块与小组件共用这一显示规则，已完成待办从投影源头移除，表数据更新后自动刷新。

显示隐私仍由逻辑卡片控制。默认仅标题；选择详细显示时，业务时间作为第二行小字出现，不放在标题右侧。逻辑卡片、Flutter 快照、原生实例绑定、点击目标和快照上限继续有效。该决定取代 ADR 0027 中 `StackView` 翻页及分页渲染部分，逻辑卡片与 Flutter 快照架构继续保留。

合同和文件/API 明细见 [Android 桌面小组件 v2 合同](../home-widget-contract.md)。
