# 同步对象经过校验，冲突裁决绑定观察到的远端版本

进入成果库之前，远端对象的 ID、frontmatter、稳定文件名、类型目录、定稿状态和内容 hash 必须一致。对象身份不符、路径越界或草稿不得写入本地。导入、墓碑传播和裁决都经过成果库，成功持久化后更新其快照。

发现冲突时保存远端 hash 与 eTag。相同远端版本只形成一个冲突副本。用户选择保留本地时，裁决针对所见远端 eTag 条件上传，成功后才更新成功同步基线；选择远端时，成果库提交远端内容及对应基线。裁决期间任一侧再次变化，重新进入冲突，不以旧决定覆盖新版本。条件失败后重新判定，每项每轮最多重判两次。

裁决意图不是成功同步基线。基线只表示双方确认的同一内容；仅用户选择不能提前清除冲突。首次接入且双方内容相同可以建立初始基线。
