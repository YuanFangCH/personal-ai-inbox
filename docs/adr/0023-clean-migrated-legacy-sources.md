# 迁移完成后清理旧格式源件，保留校验备份与完成凭据

用户于 2026-11-02 要求迁移后清理老数据。旧源长期留在活动 vault 会反复参与启动预检；仅删除源文件又会改变迁移身份，无法可靠识别中途清理或保持旧同步关闭。

完成迁移后，先逐文件核对旧源与迁移备份的 hash，再写入独立清理清单，删除非全局知识的旧格式源件（含已删除记录）。保留迁移备份、数据库/会话/设置快照、journal 和清理清单；全局知识仍是活动资料，不清理。清理中断时按清单续跑，已完成迁移的识别不依赖旧源仍存在。当前表内容与后续修改不参与清理。

此决定取代旧规格中“活动目录永久保留旧源”的要求。代价是旧资料入口在清理后不再显示，恢复旧版必须从备份显式还原；清理开始后拒绝直接 rollback 删除新格式内容。未知或已变化的旧源不删除。
