# 默认用 deepseek-flash，模型接入层保持开放

默认统一使用 `deepseek-flash`（DeepSeek-V4.1-Flash，多模态）承担文本分类、摘要、结构化与截图 OCR。但调用不写死在该模型上：接入层走 OpenAI 兼容配置，`base_url`、API Key 与模型名由用户填写，任何 OpenAI 兼容端点（含自建 vLLM / Ollama 网关）都可直接替换，业务逻辑与数据模型不变。

模型能力不由代码假定：内置常见模型的能力表（文本 / 视觉 / 结构化输出 / 上下文长度），允许用户覆盖；未声明能力时按最小能力（仅文本）处理，避免配错后以为能用。未配置 Key 时 AI 功能整体禁用，捕获、Markdown 编辑、日历、待办与提醒照常工作。

代价是客户端要自己承担能力差异适配与输出结构校验，不能用厂商独有的响应特性；好处是换模型不改代码，也不必维护多套适配器。
