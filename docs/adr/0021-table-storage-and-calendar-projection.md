# 表和表内内容分成独立的 Markdown 对象

为支持笔记式表、首页和日历的多处投影、跨表移动、旧事项保真迁移，建议表和每条内容分别以稳定 ID 文件保存；表正文和条目共享同一表 ID 归属，不把整表序列化成单一易冲突的大文件。SQLite 只做派生索引；日历和首页只投影现有内容。默认表按稳定角色识别，普通笔记默认进入事件表但保持笔记类型；既有全局知识审批例外保留。该决定用于后续实现；具体字段见[数据契约](../table-data-contract.md)，同步前仍须更新同步协议并兼容验证。30 天整表恢复材料独立于现有同步墓碑。
