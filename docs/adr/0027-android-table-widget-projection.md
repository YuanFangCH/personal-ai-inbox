# Android 桌面小组件展示多表的本地投影

逻辑卡片拥有独立 ID 和版本，由 Flutter 基于表内内容生成精简的只读快照。Android 启动器实例单独绑定逻辑卡片。原生 Provider 只处理缓存、RemoteViews、绑定与点击；写入表内容仍通过本地核心。

标准模式下秘书只读卡片配置；完全权限可管理配置，人工仍决定桌面显示隐私和实例的放置。刷新发生在数据提交、应用启动或回前台。首版不引入后台定时、Flutter 组件插件或荣耀专有接口。

此方案复用标准 Android AppWidget 和现有 Flutter 表投影，支持同一配置驱动多个实例。代价是 App 关闭时日期筛选可能显示前一天的数据，卡片会标明数据日期。API 24–30 使用固定行，较新版本用平台集合列表。合同见 [桌面小组件 v1](../home-widget-contract.md)。2026-11-10 已在 Android 15 / API 35 手机模拟器验证固定、短列表、滚动、缩放、深色、多实例、归档恢复和冷进程点击，并随 Android 手机 `v1.6.0+14` 发布；荣耀 90 真机验证延后。
