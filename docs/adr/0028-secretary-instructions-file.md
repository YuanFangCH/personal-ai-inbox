# 秘书使用本地 AGENTS.md

秘书每轮开始主动加载用户维护的长期规则。指令文件独立于成果、权限和同步；完全体模式中的明确聊天指令允许版本受控的直接编辑。本地执行器独立决定工具权限。采用单文件是为了让用户直接核对实际生效文本，并移除检索和逐条知识审批的依赖。

本决定取代 ADR 0018 以及 ADR 0020、0021、0023–0026 中关于活动全局知识的条款。旧知识在本机确认后校验归档，历史回执不改写，旧工具不再执行。

## 文件与写入边界

- 权威文件为本机 Vault 根目录 `AGENTS.md`，以 UTF-8 保存，最大 8 KiB；每轮请求读取一次快照并作为独立 system 消息注入，不进入会话历史或同步区。
- `.local/agent-instructions/` 仅保存原子写入恢复日志、幂等回执和最近一次 10 分钟撤销所需的前一版本。SQLite 不保存指令正文。
- 设置页可查看、编辑、保存、导出和撤销；保存使用文件 SHA-256 revision，冲突时要求重载，导出为 Markdown 原文。
- Agent 仅在设备级完全体模式开启、当前无附件用户消息直接提出长期指令修改时，获得本轮 `agent_instructions_read` 与 `agent_instructions_edit` 工具。编辑输入包含 `expected_revision` 和按顺序应用的唯一 `old_text`/`new_text` 项；`old_text: null` 仅可用于最后一项的末尾追加。
- 执行前重新读取当前用户消息与完全体授权代际。开关每次切换都会递增 `fullAgentModeRevision`；本轮代际变化即拒绝写入。写盘前再次检查授权，成功回执只报告实际 revision、差异及撤销期限。
- 旧全局知识导出为 ZIP，包含源文件、候选、相关冲突副本和 SHA-256 清单。ZIP 校验并写入本机归档后，才按清单逐项校验并清除活动旧数据；失败可从已保存归档续跑清理。
