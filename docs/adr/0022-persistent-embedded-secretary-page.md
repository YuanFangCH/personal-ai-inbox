# 秘书作为应用内常驻页面

日期：2026-10-31。用户确认：秘书对话由 AppShell 创建并在应用运行期间保留，手机仍显示全局底部导航，宽屏使用统一应用侧栏。切换到其他主页面只隐藏秘书，不销毁其会话、输入草稿、已选附件、思考选项或阅读位置，也不取消正在进行的模型请求；应用重启后仍从首页启动，不持久化未发送草稿。

新对话、历史会话和系统分享目标在同一秘书页面切换，不推入单独对话路由。新对话、历史切换和分享定位使用已有未发送内容确认；取消分享定位时分享会话仍保留在历史中。实际退出应用时沿用现有请求清理。该决定更新 ADR 0013、0017 对“重新进入即开新对话”和离开即销毁页面的导航生命周期约定，不改会话存储格式、模型接口、工具权限或表内操作契约。
