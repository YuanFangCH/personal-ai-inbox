# AI 对话按会话授权读取及可撤销成果操作

> 2026-10-20 补充：[ADR 0018](0018-confirmed-global-knowledge-for-secretary.md) 要求全局基础知识新增/修改必须经人工确认，为下述普通成果直接操作规则的专门例外；其删除确认与读取范围仍待用户选择。

2026-10-20 用户确认：AI 操作分为“读取 / 新增 / 修改与删除”三个权限，初始默认全部开启；应用总设置管理新会话默认值，每个会话保存自己的权限，顶部按钮只调整当前会话。读取可访问已有成果和其他会话；新增、修改和删除仅限事项、待办、日历事件、知识等成果，不允许 AI 修改、删除会话或历史消息。

在用户提出操作要求且相应权限开启时，成果修改与删除直接执行，不增加逐次确认，显示真实操作结果并支持撤销。授权由本地核心检查，模型只能提出工具请求；成果写入、版本检查、可恢复提交、幂等和墓碑仍由成果库协调。为了降低操作摩擦而接受自动副作用，代价是必须保存可供撤销的旧版本，并在执行和撤销时防止覆盖后续修改。

收件箱入口改为直接 AI 对话界面，每次从应用导航进入显示新对话；历史会话通过侧边菜单显式选择继续，App 冷启动仍进入首页。侧边菜单专用于类似 DeepSeek 手机端的对话管理，草稿、捕获确认及同步冲突迁入独立“待处理”页面。此项取代 ADR 0013 中确认入口合并到收件箱的决定；首次内容创建会话、空会话清理及删除会话不删除成果继续有效。

本决定取代 ADR 0010 中跨会话读取、成果召回及禁止 AI 修改/删除已有成果的边界；未经读取工具选择的其他会话不自动拼入上下文，隐式自动新增的原有校验继续适用。会话、工具审计与原始素材仍只在本端保存。语音限定为发送前可编辑的转文字输入及回复朗读；联网只使用当前模型接口内置能力，不支持时禁用，不另接独立搜索服务或自动更换模型/协议。文件、深度思考与上述能力的实施方案见[改造计划](../ai-conversation-redesign-plan.md)。本 ADR 记录已确认的目标契约，运行代码尚未实现。
