# AI 对话界面与操作权限改造计划

日期：2026-10-20。状态：两轮产品选择均已确认；仅规划，未开始业务实现。已确认架构边界见 [ADR 0017](adr/0017-conversation-permissions-and-reversible-result-actions.md)。下文明确区分用户决定和实施建议。

## 1. 本轮目标与已明确要求

- 将现有收件箱入口直接改为 AI 对话界面，参考用户提供的 DeepSeek 手机端五张截图。
- 新增 AI 读取已有成果、读取其他会话、修改和删除已有内容的能力。
- 权限共三组：“读取 / 新增 / 修改与删除”，初始默认全部开启。
- AI 页面顶部提供权限入口，位于参考图朗读开关的位置；应用总设置可修改默认权限。
- 总设置决定新会话默认值，各会话保存自己的权限，顶部调整不影响其他会话。
- 用户要求修改、删除成果时，在权限开启的前提下直接执行，展示操作结果并支持撤销，不逐次确认。
- AI 写操作仅限事项、待办、日历事件、知识等成果；其他会话只可读取，AI 不修改、删除会话或历史消息。
- 待处理新建独立页面；侧边菜单按 DeepSeek 手机端用于对话管理。
- 深度思考、联网搜索、语音、文件等截图能力一并纳入规划。
- 每次从应用导航进入 AI 页显示新对话；历史会话仅从对话管理中显式选择继续。App 冷启动保留首页。
- 语音限定为转文字输入（发送前可编辑）和 AI 回复朗读，不包含实时语音通话。
- 联网只用当前模型接口自带的能力；不支持时禁用按钮，不另接搜索服务。
- 本轮仅制定计划，不修改运行代码。

## 2. 页面与交互

- 顶部从左到右为历史会话菜单、当前会话标题、权限按钮、新对话按钮。
- 空会话显示简洁欢迎区；发送消息后以对话内容为主，支持现有流式回复、停止和重试。
- 底部采用圆角输入容器，保留文字、粘贴、图片预览与移除、相册和拍照入口；键盘出现时保持输入区可见。
- 侧边菜单提供历史会话搜索、按日期分组、继续会话、重命名与删除。搜索范围建议包含标题和消息正文。
- 原有草稿、捕获确认、同步冲突迁入独立“待处理”页面。建议通过主导航“更多”进入并显示数量；AI 对话侧边菜单只承载会话管理。
- 手机使用抽屉；平板、Windows 根据宽度展开会话侧栏，沿用同一套权限语义。
- 导航名称建议由“收件箱”改为“AI 对话”。是否改变 App 冷启动首页不包含在已确认要求中。
- 输入区底行提供深度思考、联网搜索开关，以及附件、语音、发送/停止入口。展开附件区提供拍照、相册、文件；已选素材显示预览、名称、处理状态与移除入口。
- 顶部权限按钮打开三个独立开关，按钮旁显示开启数量，兼顾浅色、深色及读屏；保留用户指定的位置，朗读入口放到回复操作区。
- AI 回复保留 Markdown、列表、代码块，增加复制、朗读、重试；检索和成果操作使用紧凑状态卡，失败不能伪装成已完成。
- 截图中的键盘工具栏由系统键盘提供，不作为 App 自建界面。品牌标识沿用本项目，不复制 DeepSeek 标识。
- 每次从应用导航进入 AI 页都显示新对话；同页重建、键盘弹出、权限面板或系统选图返回不触发重置。历史会话通过抽屉选择继续，退出 AI 页后再次进入回到新对话。App 冷启动沿用首页。

## 3. 已确认的权限契约

| 权限 | 作用对象与动作 | 默认值 |
|---|---|---|
| 读取 | 检索、读取本端已有成果和其他会话；不赋予修改能力 | 开启 |
| 新增 | 新建事项、待办、日历事件、知识等成果 | 开启 |
| 修改与删除 | 按用户要求修改、删除已有成果，包含手工创建的成果；直接执行、反馈并可撤销 | 开启 |

总设置保存新会话默认值；首次创建会话时复制当前默认值，之后独立保存，不随默认值变化。临时新对话可先调整权限，首次发送时连同会话落库，未发送退出不留空会话。旧会话升级时建议一次性复制迁移当时的默认值，避免旧会话长期动态跟随总设置。

总设置的导入、导出、恢复默认覆盖默认权限，不批量覆盖已有会话；权限只约束 AI 工具，不影响用户手工编辑、会话重命名/删除和点击撤销。权限默认值的迁移与旧版设置导入使用同一版本化规则。

读取采用本端检索、返回片段、必要时读取详情；用户提问需要时，AI 可自行使用已开启的读取权限，不额外弹窗，不把整个成果库或所有会话自动塞进请求。建议首批覆盖成果及其他会话的文字，来源卡可跳转到成果或对应消息。其他会话图片、文件、音频的自动读取范围尚未扩展为已确认项。

读取开关不阻断当前会话和本轮用户主动发送的内容；它控制会话外成果、其他会话的检索和读取。关闭读取后仍可新增成果；修改/删除可以使用用户明确提供的目标标识，不能以写权限绕过读取权限检索不明确的对象。执行层可以做不向模型泄露正文的身份与版本检查。

本地核心在工具调度、最终写入及恢复重放时检查当前权限；不只依赖提示词。建议关闭相关权限时中断当前生成并阻止尚未提交的相关工具操作，已提交操作保留结果和撤销。关闭读取后不再自动重发会话外原始工具片段；已经发给云端或出现在当前会话中的内容无法追溯撤回，不宣称模型已经遗忘。检索结果、历史会话、文件正文及网页内容作为资料处理，不能自行授予权限或触发与用户请求无关的改删。

## 5. 与既有决定的关系

ADR 0017 已取代 ADR 0010 中禁止跨会话读取、成果召回、修改和删除的边界，以及 ADR 0013 中确认队列合并到收件箱的部分。旧 ADR 正文保留原决定背景，并增加取代注记。术语表、可执行方案和模型接入同步说明目标契约与当前实现的区别。

首次内容创建会话、删除会话不删除成果、成果权威存储、同步白名单、墓碑、冲突裁决和凭据规则继续适用。未经用户要求的自动新增仍保留原有高置信、敏感内容、日期歧义及去重规则；开启写权限不等于允许 AI 自行整理、改删无关内容。用户明确下达新增指令时与隐式自动记录的策略区别，需在工具契约中写清楚，不能由开关隐式放开所有原有校验。

## 6. 扩展能力规划与依据

### 深度思考

输入区提供开关，按会话保存；仅对声明支持的模型启用。DeepSeek 官方当前支持显式 `thinking` 开关，并说明思考模式组合工具调用时需正确回传 `reasoning_content`，因此请求和会话存储须完整保存厂商要求的协议字段。来源：[Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)（2026-10-20 核对，尚未联网联调）。其他 OpenAI 兼容端点按各自声明处理，不能统一硬传厂商字段。

### 联网搜索

输入区提供开关，只调用当前已配置模型接口内置的联网能力，关闭时不启用联网；不新增第四组成果权限，也不隐含打开本端成果读取。请求和响应须能识别真实联网状态与来源，显示进度与引用；失败时说明未成功联网，不能把模型常识回答伪装为最新搜索结果。

2026-10-20 曾核对 [DeepSeek Search & Fetch](https://api-docs.deepseek.com/guides/search/)，它们是独立端点；用户随后明确只用当前模型接口自带能力，因此不纳入实现，即使同一厂商和 Key 也不作为绕行方案。不得自动换模型、改 API 协议或注册外部搜索厂商来点亮按钮。不支持或能力未知时禁用并说明原因；未知能力需核实当前具体端点/模型，不能凭聊天 App 的功能推断 API 支持。

当前代码使用 `/chat/completions`；[DeepSeek 对应文档](https://api-docs.deepseek.com/api/create-chat-completion/) 的 `tools` 目前仅声明函数工具。由文档与代码推断，此路径未具备可确认的内置联网，默认应禁用按钮；未用真实 Key 验证，也不将其他 API 协议的能力移植为本路径的既有能力。

### 语音

已确定基础体验为语音转文字、发送前编辑，以及 AI 回复朗读，不做实时语音通话。建议提供按住说话/点击录音、取消、转写状态、手动朗读与停止；朗读入口放在回复操作区，顶部保留权限按钮。

识别与朗读需各自确认 Android 手机、平板、Windows 的实现来源；先核实系统能力，再决定是否接独立语音服务。原项目不部署本地 AI 模型的约定继续适用；不能把调用系统能力表述为本项目已具备离线识别。外部语音服务的端点和凭据单独配置，未配置时其他对话能力继续可用。原始音频是否长期保留、跨会话读取音频不作为本次隐含决定。

### 文件

建议首批规划 TXT、Markdown、可提取文字的 PDF、DOCX、CSV、XLSX；图片沿用原有视觉输入。文件解析提取正文或表格后按模型上下文预算分段，保留文件名、页码/章节/工作表等定位信息；扫描 PDF 走支持的视觉/OCR 路径，能力缺失时明确说明。

选择文件后先显示大小、类型、解析状态和移除入口；处理失败可重试或移除，不阻塞同会话其他消息。以实际格式和解析结果校验，不执行宏、公式脚本或文件内指令，不把文档里的要求当作用户操作授权。超大文件、加密文件和不支持格式给出具体原因；大小、页数及批量数量在实现前按选定解析器和模型预算确定，不承诺任意文件。原文件留在本端；本端提取的必要内容随用户发送进入配置的模型，请求前清楚显示所选文件，原文件不进入成果同步区。模型能力不足时不自动上传整个文件到另一家服务。

文件格式与语音技术路径为实施建议，尚未选择依赖或语音服务；联网范围已锁定，不新增搜索供应商。

## 7. 成果操作与撤销设计建议

在现有 `create_result` 基础上，增加成果检索/读取、会话检索/片段读取、成果修改/删除契约。读取结果以工具消息回传模型继续生成；保留完整 assistant 工具请求、调用 ID、结果和必要协议字段，不伪造调用。限制每轮调用次数、片段总量和总时限，避免失控循环；裁剪上下文时保留完整调用/结果组，不将孤立工具结果或缺失的调用链发给模型。

修改先定位稳定 ID 并取得版本，再按指定字段更新；目标不唯一或日期不明确时只澄清事实，不要求重复授权。批量请求先固定目标列表，逐项执行，逐项显示成功、失败、未执行，不把部分成功描述为全部完成。删除经成果库写墓碑；不直接删除 Markdown 文件，不顺带删除关联成果或所属事项下的全部行动。

建议新增、修改、删除统一保留 10 分钟撤销入口，并保存操作前快照及提交后的 revision/hash；批量结果可逐项或整组撤销。撤销保存完整旧内容，以一次新的成果提交恢复，保持稳定 ID 并递增版本，不回退同步基线。后续人工修改、其他 AI 操作或同步导入已改变内容时，拒绝用旧快照覆盖并解释原因。已同步的删除撤销需作为新变更传播，不承诺远端立即恢复。

撤销材料与操作审计单独持久化，不依赖消息卡存在；重启后在期限内仍可使用，删除原会话不应级联删除未到期撤销能力。到期回收旧内容但保留必要审计；具体保留期限与旧内容清理需实现时验证。用户点击撤销是手工操作，不受 AI 开关限制。此处统一窗口与批量交互属于建议，用户目前只确认必须支持撤销。

## 8. 实施阶段与完成标准

| 阶段 | 产物 | 局部验证与完成标准 |
|---|---|---|
| A 契约与设置 | ADR、默认权限、会话权限快照、旧设置/会话迁移 | 默认全开、新会话复制默认值、各会话独立、导入导出与恢复默认不覆盖会话选择 |
| B 读取与工具编排 | 成果/会话检索与读取，结果回传模型 | 权限拒绝、来源跳转、上下文预算、停止/超时、协议字段、旧内容中的指令不触发写操作 |
| C 可撤销写入 | 新增/修改/删除、操作卡、独立撤销材料 | 权限中途关闭、版本变化、幂等、重启恢复、墓碑、批量部分失败、撤销冲突与期限 |
| D 界面重排 | 直接对话页、会话抽屉、顶部权限、独立待处理页 | 原待处理动作可达，旧会话可继续，临时会话不落空记录，分享入口与键盘不回退 |
| E 模型与联网 | 深度思考开关、当前模型接口内置联网与引用 | 当前端点/模型能力检查，不支持或未知时禁用；不调用独立搜索、不自动切模型/协议 |
| F 文件与语音 | 文件解析、预览/分段、录音转写、发送前编辑、回复朗读 | 格式/大小/加密失败、扫描 PDF 路径、语音拒绝/中断、平台能力缺失、素材只留本端；无实时通话 |
| G 三端定向验收 | 手机/平板/Windows 受影响场景及验证记录 | 浅深色、大字体、键盘、滚动、流式、权限组合、待处理与会话管理入口 |

每阶段收敛相关代码和局部验证后按项目门禁形成任务提交。用户明确开始实现前，本轮仅更新规划和权威文档。

## 9. 确认状态与实施前技术核实

产品选择已收敛：每次进入显示新对话；语音转写与朗读；仅当前模型接口内置联网，不支持时禁用。无需重复询问已确认项。

实施前核实：当前模型端点的深度思考与内置联网协议；Android/Windows 转写与朗读可用来源；文件解析器支持的实际格式及预算；撤销旧版本存储和过期清理。若需要新增收费语音服务或其他凭据，先向用户呈现具体选择，不擅自创建账号或使用未授权服务。

读取其他会话首批以文字为范围、文件格式清单、统一 10 分钟撤销窗口、文件限额属于实施建议，不冒充用户明确选择。当前无真实模型、联网或语音联调证据。
