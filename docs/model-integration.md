## 1. 原则

- 接入层开放、可替换。默认实现是 `deepseek-flash`，但不把调用写死在该模型上。
- 业务逻辑只依赖内部的结构化契约（分类结果、抽取结果），不依赖任何厂商独有的响应结构；结构校验一律在客户端做。
- 未配置模型或 Key 时，捕获、Markdown 编辑、日历、待办、提醒照常工作，AI 功能整体禁用。

## 4. 图片输入

支持的格式：JPEG、PNG、GIF、WebP，按文件实际内容判断，不看扩展名或声明的 MIME。

三种传入方式：

1. **内联 base64 data URL**：计入 48 MiB 请求体上限，本地文件最省事。
2. **外部可公开访问的 URL**：图片 ≤ 32 MiB，需 60 秒内可下载，URL ≤ 8192 字符。
3. **Files API `file_id`**：单图可到 64 MiB，适合多请求复用同一张图。

细节级别：`low` 会先缩到 512×512，更快更省；`high` / `original` 保留原图；`auto` 当前等价于 `original`。图片进入模型前会自动缩放，每张图 token 上限约 1024。

本项目的选择：

- 截图用**内联 base64**，不用 Files API——原始素材不该在服务端留存。
- OCR 用 `original` 保证中文识别质量；只做粗分类时才用 `low`。
- 配置模型后默认允许直接出网；客户端自动缩放、重编码并去除 EXIF，但不自动判断图片内容是否敏感。

## 6. 限速与错误

- 并发以**账号**为粒度，与 API Key 无关；超限返回 HTTP 429。
- 可用 `user_id` 参数做账号内的隔离：内容安全隔离、KVCache 隔离、调度隔离。取值需匹配 `[a-zA-Z0-9\-_]+`，最长 512，不得包含隐私信息。
- 非流式请求在等待期会持续返回空行，流式会返回 `: keep-alive` 注释；自研 HTTP 解析要能容忍。
- 请求发出后 10 分钟仍未开始推理，服务端会关闭连接。

## 7. 开放接入

接入方式为 **OpenAI 兼容配置化**：用户在设置里填写 `base_url`、API Key 与模型名，任何 OpenAI 兼容端点都可直接替换，包括自建的 vLLM / Ollama 兼容网关。默认预填 `https://api.deepseek.com` 与 `deepseek-flash`。

能力声明：客户端内置常见模型的能力表（文本 / 视觉 / 结构化输出 / 上下文长度），允许用户覆盖。未声明能力时按最小能力（仅文本）处理，图像相关入口自动隐藏或禁用。

未配置 Key 时：AI 功能整体禁用，捕获、Markdown 编辑、日历、待办与提醒不受影响。

输出结构校验一律在客户端完成，不依赖厂商原生的 structured output；原生 JSON Output 只作为可选的稳定性优化。

## 8. 凭据策略

- **三端共用一把 API Key**，存在各端系统安全存储里（Android Keystore、Windows Credential Manager + DPAPI），通过配置文件或设置界面填写。
- Key 不进代码、不进仓库、不写进日志；为未来开源准备的只是配置项本身，不是值。
- **每端固定一个 `user_id`**（如 `android-phone`、`android-tablet`、`win-desktop`），用于账号内的 KVCache 隔离、内容安全隔离与调度区分。`user_id` 需匹配 `[a-zA-Z0-9\-_]+`，最长 512，不得包含隐私信息。
- 为什么不用三把 Key：DeepSeek 的并发与余额都是**账号级**，与 Key 数量无关，多 Key 拿不到任何配额好处；而丢设备时换一把 Key 再同步到另外两台的代价很小。

## 9. AI 对话与自动记录

- 收件箱使用本地多会话。冷启动直接进入首页，点击“新对话”只打开临时输入页，首次发送非空文字或图片时才创建会话；未发送退出不会留下空会话，历史会话可继续追问。
- 每轮只发送当前会话最近 20 条消息，图片最多来自最近 4 条含图消息且不超过 8 张，不拼接其他会话。
- 回复使用 OpenAI 兼容 SSE 流式返回；用户可停止生成，半成品保留为“已中断”。
- 模型通过 `create_result` 工具请求新建 `matter | todo | event | knowledge`。客户端只在完整流结束后执行，并要求置信度不低于 `0.85`、非敏感、日期明确且未重复。
- 低置信、敏感、日期歧义、过去日期和重复规则进入待整理区；任何修改和删除请求不自动执行。
- 自动创建结果保留 10 分钟撤销窗口。成果被人工修改后不可撤销。
- 会话、消息和图片只在本端保存，不进入 Markdown 成果库或同步区。

图片策略：

- 配置模型 Key 后默认允许图片发送到云端，设置页提供默认开启的“允许图片发送到云端”总开关。
- 客户端发送前自动限制尺寸、重新编码并去除 EXIF 元数据，但不自动识别或遮蔽图片内容中的敏感信息。
- 该默认值由 [ADR 0010](adr/0010-contextual-ai-conversation-and-guarded-auto-write.md) 授权，取代此前逐次确认与强制裁剪脱敏的要求。
